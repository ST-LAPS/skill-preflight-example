# Skill Preflight example

ST-LAPS demonstration repository for using [Skill Preflight](https://github.com/ST-LAPS/skill-preflight) from a separate repository.

This is a test fixture maintained by the tool's author, not evidence of an external customer or adoption.

The workflow checks this repository's Arabic skill, publishes an Arabic job summary, and asserts that errors and warnings are both zero.

## العربية

مستودع توضيحي من ST-LAPS لاختبار استخدام الأداة من مستودع مستقل. ليس مستخدمًا خارجيًا أو عميلًا. افتح Actions لعرض نتيجة الفحص.
